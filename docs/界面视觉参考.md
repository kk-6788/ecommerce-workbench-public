# 界面视觉参考与验证

本次采用石墨色导航、雾紫背景、紫色主操作按钮；保留成功、警告、错误的独立语义颜色。

参考来源：
- React Bits Spotlight Card：https://reactbits.dev/components/spotlight-card ，借鉴卡片柔和高光。
- Aceternity UI Background Gradient：https://ui.aceternity.com/components/background-gradient ，借鉴渐变层次。
- Uiverse：https://uiverse.io/ ，参考按钮、输入框的交互反馈。
- Motion：https://motion.dev/docs/react-animation ，参考短时入场与按压反馈。

实现为项目原创 CSS，未复制第三方组件源码、未引入 React 或新依赖，未安装上述组件库。卡片高光为静态渐变，不是指针追踪特效。支持系统减少动态效果设置。

验证：8 项页面集成测试通过；浏览器检查桌面与 390px 手机宽度的服务连接静态预览。预览未执行服务请求，不能视为模型调用测试。

使用：打开 http://127.0.0.1:8510 ，按 Ctrl+F5 刷新以加载新样式。
