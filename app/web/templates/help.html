开始前准备

账号、服务连接和表格是作业入口，不会替你完成核验、审批或外部执行。

账号与服务连接

先双击“打开电商作业平台”。尚无账号时先创建平台账号；平台账号和模型服务账号互相独立。再按需配置自己的 API Key 或连接 LibTV。保存 Key 不等于已收费，也不代表外部服务已经接通。

进入服务连接

表格格式

可在“表格导入”下载空白模板，或下载页面内填写好的 CSV。页面草稿只保留到刷新前，请及时下载。支持 .xlsx、CSV、TSV；旧 .xls 请另存为 .xlsx。首行使用不重复列名，公式先粘贴为值，合并单元格和多行表头先整理。

上传、重复与冲突

读取后选择工作表、核对字段与前 10 行预览，再确认导入。任何一行不合格时整表不写入。普通资料按文件、工作表和原始行号识别；文件修改后会视为新来源，不会覆盖或合并旧资料。订单内容冲突时整批拒绝；导入其他工作表需重新上传并选择。

导出与数据范围

导出为 Excel／WPS 可打开的 UTF-8 CSV，包含原始资料列，不受页面最近 200 条限制。金额单位为元；以 =、+、-、@ 等开头的文本会加保护前缀。商品、货源和选品为本机共享资料；订单、销售与导入历史只显示当前账号，不导出密码或 API Key。

资料类型必填填写提醒导入结果
商品资料商品标题、品类模式为“铺货”或“研发”，空白默认铺货。商品档案，初始阶段；额外列保留为原始资料。
货源清单商品 ID、供应商、SKU先导入商品并取得完整商品 ID；拿货价、运费最多两位小数。对应商品的货源记录，初始为未核验。
选品／市场关键词、品类组分层、评分与其他市场数据只作为原始记录。选品货源词池，待核验；不会自动参与正式评分。
订单明细平台、订单号、实付金额同订单各行使用不同订单行号；订单号设为文本以保留前导零。当前账号的订单资料，可在经营复盘查看。

第一阶段选品机会 → 商品 → 预测
开始前

准备好市场表格、关键词或现有词池，并尽量收集售价、需求样本与成本资料。没有资料时，也可以先在选品页面查看已有机会。

  1. 导入市场资料

    到表格导入选择“选品／市场”，核对关键词与品类组后再确认。分层、评分和其他市场列会作为原始记录保留。

  2. 整理词池

    回到选品页面查看词池，区分待核验信息、排除项和仍需观察的机会。

  3. 创建具体商品

    把值得继续判断的机会落到真实商品，不要停留在宽泛关键词。

  4. 补事实与证据

    记录可核对的商品事实、售价、需求样本、预估成本、证据来源与仍缺的信息，事实和推测分开写。

  5. 生成并阅读预测

    预测用于决定下一步是等待补资料还是准备测试，不代表商品已经盈利。

完成标志

已建立具体商品，关键事实有证据，缺口可见，并留下最新预测。

常见错误：把关键词热度直接当成商品表现。关键词机会不等于SKU销量，必须继续验证具体商品、SKU 与货源。
进入选品与货源导入选品资料
第二阶段货源商品 ID → 报价 → 核验
开始前

先创建商品并导出商品资料，复制完整商品 ID。没有商品 ID 时，货源无法准确关联；同时准备可追溯的报价来源与来源时间。

  1. 取得商品 ID

    在表格导入页导出商品资料，找到要关联的商品并复制完整 ID。

  2. 填写货源清单

    每条记录填写供应商、SKU、规格、拿货价与运费；金额单位为元，最多两位小数。

  3. 预览后导入

    检查商品 ID 与列映射，确认供应商、SKU 和金额没有错位，再写入本机资料。

  4. 回到商品核验

    逐项核对规格、价格、运费、来源时间与供应稳定性，把状态从未核验推进到与证据相符的状态。

完成标志

供应商、SKU、规格、拿货价、运费、来源时间和供应稳定性都有记录，且核验状态反映真实检查结果。

常见错误：上传成功后直接开始制作。导入不等于核验，未核验报价不能当成已确认成本。
导入货源清单进入商品档案
第三阶段商品档案事实 → 素材 → 版本
开始前

从商品队列或选品页面先选择一个商品。直接进入档案页时如果没有商品 ID，请先选择商品，不会自动代你创建或填入资料。

  1. 核对事实与证据

    检查标题、品类、策略与当前阶段等事实，给关键判断保留证据来源，不把猜测写成事实。

  2. 核验货源与规格

    把选定供应商、SKU、拿货价、运费和商品规格对齐，确认制作内容不会与实物冲突。

  3. 补平台链接

    记录计划使用的平台页面或来源链接，保留可回查的上下文。

  4. 整理素材

    上传并检查主图、SKU 图、详情图和视频参考素材，确认文件属于当前商品，并记录素材审阅状态。

  5. 绑定修订版本

    将采用的事实、规格、货源、素材与修订版本一起记录；任何关键内容变化后，重新检查后续方案。

完成标志

阶段、事实、证据、货源、规格、平台链接、素材审阅状态和修订版本都能在同一商品下追溯。

常见错误：在未选商品时误以为档案为空就是新建成功，或更新规格后继续沿用旧素材与旧方案。
进入商品档案查看图与视频
第四阶段推视频方案 → 审批 → 发布确认
开始前

先选定商品、SKU 和已核验货源，检查事实、规格与素材齐备。教程不会自动填数据，也不会替你触发审批。

  1. 在图与视频页建方案

    进入图与视频页，为当前商品准备口播、画面提示、分镜和素材方案。此时状态是“已保存”。

  2. 先走内容审批

    内容审批是当前路径，用来确认讲什么、怎么呈现。方案已保存不等于内容已经批准。

  3. 按实际费用判断下一步

    只有方案实际涉及费用且已有费用方案时，才需要费用审批，也才需要 COST。当前网页尚不能录入费用上限、投放时长、指标、停止条件，因此不能在这里完成付费投放方案或费用审批。付费投放方案和费用审批只能先准备，另行补齐后再确认。

  4. 确认当前所需审批后再生成

    不涉及费用的方案按当前内容审批结果推进；涉及费用的方案须等待费用路径另行补齐。方案已保存不等于视频已生成。

  5. 人工审阅成片

    生成完成只表示已有成片文件。人工检查商品一致性、规格、字幕、节奏和风险；需要调整时先修改口播、画面提示或分镜，修改后形成新版本，再重新审阅。

  6. 准备并核对发布方案

    上架启动页可准备内容方案并查看、核对已有发布方案，但当前不能录入付费投放条件。账号、目标与仍缺的费用条件应另行补齐；发布前仍需你确认。

  7. 保留真实发布回执

    当前平台还不能登记发布结果。实际发布后，请先在平台外保留账号、链接、时间与结果回执；待结果登记能力接入后，再按真实结果记录，失败、未知或待确认不能写成“已发布”。

完成标志

平台内已保存方案并完成当前可用的内容审批；平台外已保留真实生成、审阅与发布回执。只有确实涉及费用并在后续补齐费用方案时，才记录费用批准；发布结果须待登记能力接入后再按回执写入。

常见错误：把脚本、方案或生成任务当成成片，把内容审批当作费用审批，或把上架启动页当成付费投放方案录入页。这里不声称任何外部生成、费用审批或发布已经完成。
