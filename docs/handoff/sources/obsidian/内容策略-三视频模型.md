# 三视频模型：概念前置策略

> 当产品已上线但无用户反馈/数据时，不拍产品多好（没数据撑）、不继续拍开发过程（拍过了），改拍 **下一个待研发的概念**。

## 策略背景

2026.7 凉凉衣/救生衣已上线，抖音内容从 "记录上线过程" 自然过渡到 "下一个要做什么"。

核心逻辑：**用痛点引发共鸣 → 概念制造期待 → 决策展示专业度。**

## 三视频模型

每款新产品发布前走三集：

```
痛点篇 → 概念篇 → 决策篇
```

### ① 痛点篇
- 核心：引发共鸣，让观众觉得 "对对对这就是我遇到的"
- 不暴露要做什么产品，只讲问题
- 案例：下雨天遛狗穿脱雨衣的麻烦

### ② 概念篇
- 核心：展示解决方案概念
- 用 AI 生成概念示意图 / 3D 演示
- 让观众看到 "还能这样" 的新鲜感

### ③ 决策篇
- 核心：展示设计过程中的思考和取舍
- 为什么选这个方案不选别的
- 细节考究展现专业度

## 与原有内容策略的关系
