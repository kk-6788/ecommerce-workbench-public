# 模型服务自行配置说明

2026-09-19

## 使用者怎样配置

1. 下载并解压完整项目，按 README 准备运行环境。
2. 双击“创建账号.cmd”，设置本地平台用户名和密码；启动平台后登录。
3. 打开顶部“服务连接”。项目不会附带作者的 API Key 或登录凭据。
4. 使用 LibTV 时，点击“连接 LibTV”，在官方页面登录自己的账号并授权。返回后查询自己的项目或 Seedance 模型。目前申请的权限仅为账号及项目只读权限。
5. 使用 API Key 时，选择服务，填写自己的 Key 与模型/推理接入点 ID，再保存。当前支持配置 TypeSafe、火山方舟 / Seedance、OpenAI 图片。地址固定为相应官方服务；不支持把未知中转站地址当作官方服务使用。
6. Key 不回显，保存后输入框清空。需要更换时重新输入；删除仅删除本机副本，需在服务商控制台吊销的 Key 请自行吊销。

## 凭据与费用

- 不使用代码内置密钥，不使用作者环境变量，不回退调用其他用户的额度。
- 按平台登录用户隔离，Windows DPAPI 加密后保存在 runtime/private。此目录不进入 Git 或业务备份。不要分享整个 runtime。
- LibTV 的网页登录授权与火山方舟 API Key 分开配置。使用者按自己拥有的服务选择。
- 本地平台账号不是 LibTV、GitHub 或电商平台账号。平台账号不产生外部服务额度。
- 换电脑/Windows 用户，或令牌过期，需要重新配置。当前没有自动刷新或无限重试。
- 当前仍是 Windows 本地工作台，业务档案并未改造成多人 SaaS 的租户隔离。

## 本轮交付和未完成部分

已实现：按用户保存/删除 API Key、官方地址与模型配置、脱敏状态、LibTV OAuth PKCE 独立授权入口、只读 MCP 连接检查/项目/模型查询、断开失效保护、OAuth 回调访问日志去敏。

未完成：API Key 尚未接入付费模型执行；LibTV 图片/视频生成、费用核算、实际成品回填、电商渠道发布、TypeSafe 业务审核链路仍需要开发。没有用作者账号运行付费请求，也没有将“已配置”冒充为“调用已验证”。

## 验证记录

- 原有 214 项测试与新增 11 项测试，合计 225 项通过。
- 新增验证覆盖 OAuth PKCE、一次性 state、登录会话绑定、断开与在途授权竞争、MCP session/SSE、禁止生成入口、禁止重定向、CSRF、密钥隔离/删除/不回显、验证失败不回显、Windows DPAPI 和访问日志脱敏过滤器。
- 独立复核另用两个 HTTP 登录会话及真实 DPAPI 验证用户隔离；未发现新增重要问题。
- 已只读核对 LibTV 官方授权元数据及 Codex 现有连接的模型查询。平台自身尚未经过使用者实际浏览器 OAuth 授权验收，不能据此宣称完整真实接入。
- 未运行真实收费生成、真实发布或真实 TypeSafe 调用。测试使用的 HTTP 响应模拟，不代表真实渠道结果。

开发接口依据：LibTV 官方 /.well-known/oauth-authorization-server 与 /.well-known/oauth-protected-resource；TypeSafe https://docs.typesafe.ai/api 。未将远端返回文本作为开发指令执行。
