# 电商作业平台 UI 主题与场景教程设计

日期：2026-09-19  
状态：已经用户确认视觉方向，待实施计划  
范围：现有 FastAPI + Jinja2 + 原生 CSS/JavaScript 本地网页工作台

## 1. 目标

1. 清理页面上直接显示的字面量 `\n`，并防止同类问题再次出现。
2. 在不改变业务状态、审批规则和技术栈的前提下，统一整个工作台的视觉语言。
3. 提供四套可切换、可记忆、各自完整协调的配色。
4. 把“使用教程”升级为面向真实作业的教程中心，覆盖选品、货源、商品档案和推视频。

## 2. 已确认的问题

`app/web/templates/selection.html` 的内容块开头以及 `app/web/templates/review.html` 的两处位置，存在源文本字面量 `\n`。Jinja2 不会将它转换为换行，而是原样输出到 HTML，因此浏览器页面显示了 `\n`。

修复方式：

- 用真实换行替换模板中的字面量。
- 检查所有 Jinja 模板是否还有同类文本。
- 在页面集成测试中断言选品页和复盘页的响应正文不包含该字面量。

## 3. 设计方向

### 3.1 产品语气

这是个人电商经营者的本地作业台，而不是营销展示页。设计关键词是“精准、稳定、有层次、能长时间使用”。高级感来自字体层级、空间秩序、表面材质和克制的反馈，不依赖大面积高亮渐变或持续动画。

### 3.2 标志性元素

页面顶部使用“作业轨道”：将当前模块、所处阶段、待审批数和快捷动作组成一条安静、连续的上下文带。它让使用者始终知道“我在哪里、现在做什么、下一步去哪里”。

### 3.3 参考落地

- Uiverse：参考按钮、输入框的 hover、active、focus 与 disabled 反馈。
- React Bits Spotlight Card：参考指针附近的局部柔光，仅用在可操作的教程卡和主要工作卡。
- React Bits Aurora：参考层叠颜色和氛围深度，实现为低对比静态背景，不引入 WebGL。
- Aceternity Bento Grid：用于教程首页和数据总览的主次分组。
- Aceternity Moving Border：只转化为“当前任务/待确认”的单次、低强度边界提示，减少动效时保留静态高亮。

所有样式均在项目中独立实现，不复制第三方组件源码，不引入 React、Tailwind 或新运行时依赖。

## 4. 主题系统

主题使用 `data-theme` 属性和 CSS 自定义变量。JavaScript 在页面绘制前应用保存的选项，并使用 `localStorage` 记忆本浏览器偏好。无保存项时使用曜石紫。

| 主题 | 背景 | 深色表面 | 主强调 | 浅色表面 | 主文字 |
| --- | --- | --- | --- | --- | --- |
| 曜石紫 | `#F5F2FA` | `#24212E` | `#7654C5` | `#FFFFFF` | `#282436` |
| 海盐蓝 | `#F2F7FB` | `#17354C` | `#3478C9` | `#FFFFFF` | `#1E3344` |
| 松露绿 | `#F2F7F5` | `#193A33` | `#2F806C` | `#FFFFFF` | `#203A34` |
| 琥珀沙 | `#FAF5ED` | `#463426` | `#B86E2D` | `#FFFEFC` | `#3C3027` |

成功、警告、错误等语义色保持含义一致，但为每套主题调整浅背景和文字对比。颜色不是唯一状态信号，同时使用文字、图标或边框。

主题切换器位于桌面端侧边栏底部；移动端放入顶栏的紧凑弹出面板。四个选项显示名称和色彩样本，并具有明确的键盘焦点与当前选中状态。

## 5. 页面与组件

### 5.1 全局结构

```text
桌面端
┌─侧边导航───────┐┌─作业轨道／页面标题─────────┐
│ 品牌              ││ 阶段·状态·主要动作          │
│ 业务导航          │├─主要内容区──────────────┤
│                   ││ 主卡片 / 数据表 / 表单        │
│ 任务状态          ││                                │
│ 主题切换          ││ 次要卡片 / 下一步建议          │
└──────────────────┘└────────────────────────────┘
```

移动端保留顶部品牌、横向导航和紧凑状态，卡片、表单与教程网格改为单栏。表格使用显式滚动容器，不因缩放而丢失列。

### 5.2 组件层

- 作业轨道：页面标题、说明、状态和一个主动作。
- 表面卡片：标准、主要、待处理三种等级，层级由边框、阴影和标题区区分。
- 数据表：粘性表头、数字对齐、长文本换行、行 hover 和空状态。
- 表单：统一标签、帮助文字、错误和成功反馈；主操作位置稳定。
- 标签与徽章：使用中文可理解状态，技术枚举作为次要补充。
- 教程卡：显示适用阶段、预估步数、前置条件和“开始教程”动作。

### 5.3 动效系统

动效用于表达层级、状态变化和操作反馈，不做与任务无关的持续装饰。

- 页面入场：页标题、主卡片和次要卡片使用 180–320ms 的分层淡入与微小位移，只执行一次。
- 主题切换：背景、表面、边框和文字在 180–240ms 内过渡，切换按钮使用选中环和轻微缩放确认。
- 教程路径：四阶段连接线在教程页入场时逐段点亮；展开教程时，当前阶段进入清晰高亮。
- 当前任务：只在待处理或待确认卡片使用低强度边界流光，周期不少于 4 秒，不用于普通卡片和表格。
- 指针反馈：可操作卡片使用非跟随式的局部柔光；按钮在 hover/active 时仅做边框、阴影与 1px 位移反馈。
- 内容稳定：表格行、数值、输入区和长文本不做自动漂移、缩放或循环闪烁。
- 减少动效：`prefers-reduced-motion: reduce` 下将动画、平滑滚动和非必要过渡统一关闭，用静态边框、背景和文字保留状态含义。

## 6. 教程中心

### 6.1 首页结构

顶部给出“从选品到推视频”的四段路径，下方使用 Bento 式卡片呈现四组核心教程。表格导入、账号和服务连接作为“开始前准备”，不与业务教程混在一张长文档中。

### 6.2 四组必备教程

#### 选品

1. 导入或整理选品/市场资料。
2. 阅读词池的记录分层、当前判定与来源。
3. 创建具体商品，补充售价、需求样本、成本和来源证据。
4. 生成预测，辨别“已记录数据”与“已核验事实”。

完成标志：已形成具体商品档案，且关键判断可追溯到证据；不把关键词付款量当成具体 SKU 销量。

#### 货源

1. 先创建商品并取得完整商品 ID。
2. 逐条录入或批量导入供应商、SKU、规格、拿货价和运费。
3. 核对价格单位、规格一致性、供应稳定性和来源时间。
4. 只有实际核验后才更改核验状态。

完成标志：货源已关联正确商品，价格和规格可追溯，“未核验”不被界面误导为可直接上架。

#### 商品档案

1. 选择商品，检查品类、模式、阶段与修订版本。
2. 核对事实、来源证据、货源、规格和平台链接。
3. 检查主图、SKU 图、详情图、视频和审阅状态。
4. 核对素材与方案的版本绑定，避免审批后内容变更。

完成标志：档案能回答“商品是什么、数据从哪里来、用哪个货源、当前素材和版本是什么”。

#### 推视频

1. 确认商品、SKU、货源和可用素材。
2. 在“图与视频”创建方案，填写口播/画面提示和分镜。
3. 确认内容审批；涉及生成、重试或投放费用时，再独立确认费用审批。
4. 生成后审阅成片，有修改则形成新版本，通过后再进入发布方案。
5. 发布或投放前再核对账号、目标、预算上限、时长、指标和停止条件。

完成标志分级呈现：方案已保存、内容已审批、费用已审批、成片已生成、已人工审阅、已发布。较低阶段不冒充较高阶段；当真实执行连接尚未可用时，教程明确标注“当前只完成准备”。

### 6.3 教程交互

教程使用页内锚点和原生 `<details>` 展开单元，确保无 JavaScript 时仍可阅读。“去操作”按钮链接到对应的现有页面，不自动替用用户填写数据，不自动审批或触发外部动作。

## 7. 数据与状态流

```text
启动页面
  → 在首次绘制前读取本地主题偏好
  → 应用 data-theme 和完整设计变量
  → 用户切换主题
  → 更新 data-theme、选中状态和 localStorage

进入教程
  → 选择业务场景
  → 阅读前置条件与操作步骤
  → 通过直达按钮进入现有业务页
  → 用现有业务规则完成数据与审批流程
```

主题状态只保存视觉偏好，不保存账号、商品、密钥或审批数据。教程不新增业务状态，仅解释现有功能与边界。

## 8. 异常与降级

- `localStorage` 不可用时：保持曜石紫，当次切换仍生效，不影响业务功能。
- 未知主题值：回退到曜石紫，不将未验证的值写入 DOM 类名。
- JavaScript 禁用：默认主题正常显示，教程正文可读，业务端现有无 JS 边界不因本改造扩大。
- 减少动效：完全停止背景移动、卡片进场和边框动效，焦点与选中状态依然明确。
- 长中文与窄屏：按钮和标签允许合理换行，表格用滚动而不裁切内容。

## 9. 验收与测试

### 9.1 自动化检查

1. 选品页与复盘页渲染结果不包含误写的 `\n` 字面量。
2. 教程页包含“选品”“货源”“商品档案”“推视频”四个主题以及对应直达链接。
3. 基础模板包含有效主题切换控件，四个主题值有白名单。
4. 现有登录、选品、商品、素材、发布、复盘、导入和审批集成测试保持通过。

### 9.2 真实浏览器检查

- 桌面宽度与 390px 移动宽度。
- 四套主题的侧栏、作业轨道、卡片、表格、表单、状态和教程页。
- 主题切换后刷新页面仍保留选择。
- 键盘导航、焦点轮廓、长中文、空状态和表格滚动。
- `prefers-reduced-motion: reduce` 下不存在持续动效。
- 普通模式下验证页面入场、主题过渡、教程路径和当前任务边界动效；动效不得造成布局跳动或遮挡操作。

### 9.3 不在本次范围

- 不新增真实电商平台采集、视频生成、发布或投放连接。
- 不改变内容审批、费用审批、方案哈希、幂等或对账规则。
- 不用教程文字声称尚未实现或未验证的执行能力。
