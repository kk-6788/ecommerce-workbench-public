使用教程

从创建账号到导入、整理与导出资料。

第一次使用

  1. 双击项目里的“打开电商作业平台”。
  2. 尚无账号时，在登录页创建账号；已有账号直接登录。密码框可切换显示。
  3. 进入“服务连接”，按需配置自己的 API Key 或连接 LibTV。
  4. 进入“表格导入”，先整理商品，再关联货源。

平台账号和模型服务账号互相独立。保存 Key 不会自动收费；当前部分制作执行能力仍在接入中。

填写表格模板

在“表格导入”选择资料类型，点击“下载空白模板”，或者在页面内填写后点击“下载填写好的 CSV”。模板草稿只存在当前页面，刷新前请保存。

资料类型必填注意事项导入结果
商品资料商品标题、品类模式为“铺货”或“研发”，空白默认铺货。商品档案，初始阶段；额外列保留为原始资料。
货源清单商品ID、供应商、SKU先导入商品并导出商品资料，复制完整商品ID。拿货价、运费单位为元，最多两位小数。对应商品的货源记录，状态为未核验。
选品／市场关键词、品类组分层或评分仅作为原始记录；其他市场数据列也会保留。选品货源词池，待核验；不会自动参与正式评分。
订单明细平台、订单号、实付金额同订单多条明细须有不同的订单行号。订单号请在 Excel 中设为文本，保留前导零。导入中心的订单资料；经营复盘有查看入口。
销售汇总平台、日期、销售额日期为 YYYY-MM-DD；订单数为非负整数。可添加商品名称等列。导入中心的销售资料；不会自动与订单明细累计。

上传与确认

  1. 选择类型与文件，点击“读取并预览”。支持 Excel .xlsx、CSV、TSV，旧 .xls 请另存为 .xlsx。
  2. 选择一个工作表；核对每个业务字段对应哪一列。星号字段必填。
  3. 查看前 10 行预览，确认后点击“确认导入此工作表”。
  4. 任何一行不合格，整张表不写入。按提示修正原文件，再重新上传。

限制：4 MB、每表 1000 条数据和 60 列，工作簿最多 20 个工作表。首行必须是不重复的列名，公式需先粘贴为值。合并单元格、多行表头请先整理。

重复与冲突

普通资料按相同文件、工作表和原始行号识别重复上传，内容相同的两行不会被误删。文件修改后视为新的来源，不会自动覆盖或合并旧资料。订单按平台、订单号和订单行号识别；同一身份内容改变时整批拒绝，先核对冲突再处理。导入其他工作表需重新上传并选择。

导出与数据范围

选择资料类型后点击“导出当前类型数据”，下载可用 Excel／WPS 打开的 UTF-8 CSV。导出不受页面最近 200 条显示限制。商品、货源和选品为本机共享业务资料；订单、销售和导入历史仅显示当前账号的数据。不会导出账号密码或 API Key。

导出包含原始资料列，金额单位为元。为防止公式执行，以 =、+、-、@ 等开头的文本会加保护前缀。导出再导入用于迁移或整理，不是自动更新已有记录；请先检查重复与冲突。

经营与审核

原始表格只是来源资料，不等于已核验的事实、成交凭证或可直接执行的方案。请继续补充证据，在商品档案核验货源，按平台审批流程推进。订单和销售导入目前用于资料存档、查看与导出，不会自动生成利润结论或修改模型。
