# 界面视觉参考与验证

## 主题与设计策略

界面提供四套可见主题：黑曜（`obsidian`）、海洋（`ocean`）、森林（`forest`）与琥珀（`amber`）。主题不直接在各组件中写死颜色，而是由语义 token 统一驱动背景、表面、正文、弱化文字、边框、品牌色、焦点、阴影及成功/警告/错误状态；组件只消费 token。这样可在保持信息层级、焦点可见性和状态含义一致的前提下切换整体氛围。

视觉与交互借鉴以下公开设计方向：

- Uiverse：按钮、输入框和控件状态的即时反馈。
- React Bits Spotlight 与 Aurora：卡片柔和聚光、环境色和渐变氛围。
- Aceternity UI Bento Grid 与 Moving Border：教程信息的疏密分组、当前任务边界强调和缓慢流动感。

最终实现均为项目原创 CSS/JavaScript，没有复制第三方组件源码，没有引入 React，也没有新增或安装上述组件库及其他依赖。卡片光感由静态渐变实现，不是指针跟随的 Spotlight 组件；Bento 与 Moving Border 仅作为构图和动态节奏启发。

## 真实浏览器验证

测试服务使用独立端口 `8521` 和临时数据目录，不接触正式 `runtime`。在 Chrome/Edge 中实测 `/help` 可访问，并完成以下检查：

- 桌面视口逐一选择黑曜、海洋、森林、琥珀四个可见主题按钮；每次切换后，根元素 `data-theme` 与所选主题一致，四个按钮中仅对应按钮的 `aria-pressed="true"`，刷新后主题仍保持。
- 390px 视口检查 `/help` 和 `/selection`：两页均无整页横向溢出；选品页表格仅在自身容器内横向滚动，不撑宽页面。
- `/selection` 与 `/review` 的可见文本中没有把字面量 `\n` 显示为独立内容。
- 普通动态模式下，教程路径使用 `journey-connect`，时长 0.52 秒；当前任务强调使用 `task-border-flow`，时长 5.5 秒。页面状态保持可读，动画未造成可见布局跳动。
- 模拟 `prefers-reduced-motion: reduce` 后，受检元素动画为 `none`，过渡被压缩到 0.00001 秒，页面状态与当前选中项仍清晰可见。
