# 电商上架素材管线（1688 供应商素材 → 主图/详情/视频交付）

把 1688 供应商商品页的素材（主图/视频/详情长图）整理并做经用户要求的轻量改造，交付可检查的上架素材或改图包。实际抓取、下载、生成和发布都必须以当前宿主可用能力及用户明确请求为边界。
源头方法 =「猫砂伴侣」管线（2026.8.31 首次，2026.9.3 比亿奇猫砂二次验证）。

## 管线四步（顺序不可乱）

### ① 抓取（CDP 连用户 Chrome 9222，playwright connect_over_cdp）

**主图 = 按轮播 DOM 顺序抓，不是网络层全量抓。**
- 定位 `detail-gallery / .gallery / .swiper / .od-gallery-list` 容器（找不到才回退全页 img），过滤 `cbu01.alicdn.com/img/ibank` 前缀的图。
- ⚠️ 新版详情页所有图库缩略图在一个 `.od-gallery-list` 里（`[class*=gallery]` 正好命中它）——返回的是**图库全部图**（一个 listing 可达 30+ 张），不是 5 张主图。抓到 30 张不算抓错，但要自己分类，别默认前几张就是主图。
- 轮播顺序 = 上传顺序；**主图1 = 该商品主视频的 poster 图**（同 URL 出现两次可验证）。
- ⚠️ 同一图库容器里会挂**搭配销售的另一款产品**（实例：牵引绳 listing 的图库里 18 张是配套项圈，还是另一个品牌）→ 必须按内容分目录，别当同款主图一起交付。
- 分类方法：PIL 拼 contact-sheet（4-6 列，每格标 `#01`…`#NN`）→ **一次** `vision_analyze` 让它逐段归类（卖点主图 / 白底产品图 / 详情图 / 搭配的其他产品），别逐张 vision。
- 分类后文件名带**内容标签**（`01-主图-<品名>-<卖点>.jpg` / `05-白底产品图-配色1.jpg` / `06-尺码表-酒红.jpg`），下游（用户或第三方 AI）才知道每张该干什么。
- ⚠️ 网络层拦截（`page.on('response')` 抓 alicdn image >8KB）会**过度抓取**，混入：
  - 相关推荐/关联商品的其他品牌图（比亿奇案例：混进匝宝木薯猫砂 3 张）
  - 分销平台标识（智淘/妙手/掌中宝分销）、1688 铺货/代发/采购广告
  - 同品牌不同产品线（狗砂、木薯砂 vs 膨润土砂）
  → 主图必须用轮播 DOM 顺序抓 + 与网络层结果哈希去重，不能用网络层全量当主图。

**详情长图 = 懒加载滚动到底 + 网络层拦截**（DOM 遍历拿不到懒加载图）。
- 滚动到底用随机步长（400-900px + 随机间隔 + 偶尔回滚），别机械匀速。
- 详情长图特征：宽>=700 且 高>宽（比亿奇案例 790px 宽竖版）。

**视频**：
- `caiyuanbao.alicdn.com/...published_mp4_264_hd_taobao.mp4?auth_key=...` 可 `curl -L -H Referer: https://detail.1688.com/` 直接下载（auth_key 带有效期，趁会话内下载）。
- `cloud.video.taobao.com/play/...` 无 auth 返回 HTTP 490 —— 别硬试，用上面 caiyuanbao 镜像源。
- 一个 offer 可能挂多个视频（产品宣传 + 工厂生产），都要用 video_analyze 验内容再命名。

### ② 清理（格式 + 过滤 + 去重）
- **真实格式校验**：头字节探测（RIFF..WEBP / \xff\xd8\xff / PNG 头），WebP 伪装成 .jpg 的必须转真 JPG（PIL quality=95 或 ffmpeg），否则平台拒收。真 .webp 主图淘宝/抖音可直传，不用转。
- **SKU 缩略图剔除**：网络层抓到的小图（220-250px）会混进详情候选，交付前必须按 `min(w,h)>=700` 复查，低于的一律剔除（比亿奇案例 2 张 250x250 误入详情，返工）。
- **哈希去重**：详情图与轮播主图按 md5 去重，避免同内容不同分辨率重复交付。
- 无关素材（其他品牌/分销标识/广告/店铺服务信息/占位图/图标）在 contact-sheet 分类后剔除。

### ③ 主图1 差异化改图（灵镜，免费 0 积分）
差异化是红线：直接复用别家主图会触发淘宝同款合并/抖音同图限流。
- **CLI 直调**（比 CDP 配方快）：`lingjing image generate --prompt "..." --reference <原图> --size 2048x2048 --count 1 --wait --output-dir <dir>`（实际输出 1254x1254，够用）。
- prompt 写法：先 `vision_analyze` 逐字提取原图全部文字 → **逐字内嵌**到 prompt（品牌/品名/卖点/角标全保留）→ 换背景/构图/光影做差异化 → 追加「严禁编造检测数据、检测报告、认证信息、参数数字」。
- 白底产品图 → 换居家场景（猫砂盆/木桌/绿植虚化）是性价比最高的差异化方向。
- 生成后 10 项 vision 验证：各组文字逐字 ✅、包装与参考图一致 ✅、背景已差异化 ✅、无编造数据 ✅，任何一项缺字/改字 → 重跑。

### ④ 交付（对齐猫砂伴侣结构）
```
D:/Hermes 交付/<产品>-详情页/
  README.txt                    ← 交付说明+上传注意+红线
  <产品>-素材完整清单-YYYYMMDD.txt
  01-<品牌品名>/                ← 按上传序号连续编号
    01 主图1-xxx.png/webp
    02 主图2-xxx.webp
    ...
    NN 视频-产品宣传xxs.mp4
```
- 编号连续（01→N），先 vision 给每张图定内容名，再复制。
- 交付前全量复查：真实格式 + 尺寸 + 编号连续性。
- ⚠️ 重建/重编号时，交付目录里的文件可能被资源管理器预览/看图程序锁定（WinError 32），删除会失败——重试+跳过，README 里标注残留文件等占用方关闭后手动删，别硬删。

### ⑤ 交付给第三方 AI 改图（用户自己转发给 GPT）

KK 的常用路径：**不是我调灵镜生图，而是把「原图 + 改图要求」打包 zip，他自己发给 GPT/ChatGPT 改**。这时交付物就是一个 zip，别自作主张先生成图。

```
改图包-给GPT-YYYYMMDD.zip
  00-改图要求-给GPT.txt      ← 通用规则 + 逐图要求 + 验收清单
  <产品名>/                  ← 图片按内容命名，不是 01/02/03
    01-主图-<品名>-<卖点>.jpg
    05-白底产品图-配色1.jpg
```

`00-改图要求` 固定三段：
1. **通用规则**：产品本体 100% 不变（颜色/结构/比例/细节）/ 原图卖点文字含义逐字保留（可重排版不可改字漏字）/ 只改背景场景构图光影 / **严禁编造检测数据·认证·参数数字** / 禁止加新品牌 logo 水印 / 输出 800x800（淘宝）与 1080x1440（抖音）/ 浅色明亮电商风 / 同款多图风格统一。
2. **逐图要求**：按图号指明保留什么、改什么（引用文件名）。
3. **验收清单**：本体一致 / 文字没漏没改 / 背景已差异化 / 无编造数据 / 尺寸 / 风格统一。

包里还要给「**产品事实**」清单（品名/结构/材质/现有卖点原文/颜色尺码），写明「只能用这些，不许自己加卖点」——GPT 最常犯的错就是替产品编数据。

纪律：
- 打包前把 WebP 伪装图转真 JPG（见 ② 清理），别把会被平台拒收的文件塞进包。
- 视频默认**不进**这个包（单个可达 48MB）——单独存目录，用户要再给。
- `zipfile` 打包后**回读列一遍**文件名+大小，核对文件数与内容标签是否对得上再交付。

## 红线（沿用猫砂伴侣规范）
1. 全程保留厂家品牌字（用厂家牌上架）。
2. 禁止加入 AI 短剧 IP 角色（榴莲/芒果等）。
3. 不编造检测数据——图中数据为厂家原图自带，改动/自建必须核实。
4. 数据/卖点文案只保留在对应真实货源的图上，不跨款挪用。

## Pitfalls 速查
- 网络层拦截 ≠ 主图清单，必须按轮播 DOM 顺序重抓主图。
- 主图1 = 主视频 poster。
- 图库容器（`.od-gallery-list`）装的是**全部图**不是主图，30+ 张正常。
- 图库里会混进搭配销售的另一款产品/另一个品牌 → contact-sheet + vision 分类后再命名。
- 图上品牌英文可能与详情页参数栏「品牌」字段不一致（实例：图印 BORORO LABORATORY vs 参数栏写 Pinterchains/品特链条）→ 不裁决谁对，写进交付说明并提示铺货前向客服核实授权。
- 250px 缩略图会混进详情候选 → min(w,h)>=700 复查。
- 交付目录文件可能被 Explorer 锁住删不掉 → 跳过并标注。
- 品牌名不能照用户口述写（比亿奇≠比翼双飞/比翼齐），以包装图 vision 确认为准。
- 用户口述的商品名可能来自 1688 的 SEO 堆词标题，不是图上真名（「双段式狗狗牵引绳…P绳」→ 图上产品名「彩云渐变双排牵引绳」）；写文案以图上文字为准。
