# 图标、表格导入与数据导出

## 打开平台
双击项目根目录“打开电商作业平台”。浏览器访问 http://127.0.0.1:8510 。
左侧新增“表格导入”和“使用教程”。

## 填写与导入
1. 选择商品资料、货源清单、选品／市场、订单明细或销售汇总。
2. 下载空白 CSV 模板，用 Excel／WPS 填写；也可直接使用页面内的在线模板，增加行后下载填写好的 CSV。
3. 选择 .xlsx、.csv 或 .tsv 文件，点击“读取并预览”。
4. 多工作表时选择一张，核对字段映射及前 10 行预览。
5. 点击“确认导入此工作表”。有错误时整张表不写入，按行号修改后重新上传。

在线草稿只保存在当前页面，刷新前请下载。支持 UTF-8 与 GB18030 CSV／TSV，首行为不重复的列名。每文件最多 4 MB、每表 1000 行数据／60 列、Excel 最多 20 张工作表。公式请先粘贴为值，.xls 请另存为 .xlsx。

## 字段与去向
- 商品：商品标题、品类必填；模式填铺货／研发。进入商品档案，其他列作为原始来源保留。
- 货源：商品ID、供应商、SKU必填。先导出商品资料取得完整ID；金额单位元，最多两位小数。进入对应商品档案，未核验。
- 选品／市场：关键词、品类组必填；评分／分层和其他字段作为原始资料保留，进入词池，待核验。
- 订单：平台、订单号、实付金额必填。同订单多条明细填写不同订单行号。
- 销售：平台、日期、销售额必填；日期 YYYY-MM-DD，数量非负整数。
订单与销售进入导入资料，经营复盘有查看入口；目前不自动生成指标、利润或模型结论。

## 导出
选择类型后点击“导出当前类型数据”，获得 UTF-8 CSV，可用 Excel／WPS 打开。导出不受页面最近 200 条限制。
商品、货源和市场资料为本机共享业务数据；订单、销售及导入历史仅属于当前账号。导出不含账号凭据或模型密钥。
商品导出包含完整商品ID；货源金额以元导出；原始资料保留在 JSON 列。
CSV 对公式开头字符加保护前缀。Excel 订单号列应设为文本以保留前导零。
导出后再次导入不是更新或覆盖操作，请先核对。

## 重复和冲突
普通资料以同文件、工作表和行号识别重复上传，同内容的独立两行不会误删。修改文件视为新来源。
订单按平台、订单号、订单行号识别，内容不一致时整批拒绝，不覆盖已有记录。
预览有效期 24 小时；一次导入一张工作表，其他工作表重新上传后选择。
