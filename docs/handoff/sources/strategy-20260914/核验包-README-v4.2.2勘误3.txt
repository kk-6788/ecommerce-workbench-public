【勘误3说明（检查人第七轮核验 1 项全采纳）】

检查人第七轮指出模型稳健性隐患：异常词仍参与同品类基准——
「已判数据待重抓（价格一致性存疑）的词，仍反过来充当其他词
是否异常的'正常基准'」。逻辑上：A 被判定数据不可信，但 A 的
数据仍可证明 B 正常。词池扩张时易出现异常价格相互抬高基准、
互相掩护。

检查人倾向加这一条（乙方同意）：
  「同品类基准池排除所有已被判定为数据待重抓的词；异常词
  修复并重新通过有效性检查后，方可重新进入基准池。」

加入后实际影响（乙方全量迭代复核，与检查人一致）：
  狗狗衣服小型犬冬装：跨度 14.96/5.2=2.88 倍>2；排除异常词
  （冬季加厚/边牧/杀菌）后服饰组基准从 11.625 降至 9.525
  （马甲10.45/狗套8.6/带牵引环12.8/鹿犬6.5 中位数）→ 偏差
  +57.1%>±50% → 第 4 个数据待重抓。
  迭代确认无连锁第 5 个（第1轮3词 + 第2轮小型犬冬装后收敛；
  剩余词全部不触发）。
  分层变化：数据待重抓 3→4，暂缓/换货源 8→7。

【评级规则（v4.2.2 勘误3版，保守口径，需求门槛入规则）】

净利公式不变：
  投流前贡献利润 = 售价 × (1-5.5%佣金-8%退款率)
                  - 综合采购到单成本(拿货保守价+代发运费4+包材0.5)

过线标准：
  T1: 贡献利润中位档≥8元 且 净利率≥25% 且 头部付款≥2000
  T1候选: 同T1但1688样本过少(<3)，锁厂实价复核后转正
  T2: 贡献利润中位档≥3元 且 拿货/中位价≤50% 且 头部付款≥1000
  T2观察型: 贡献利润中位档≥2.5 且 +10%档≥3.5 且 拿货/中位≤30%
            且 头部付款≥1000（四条件缺一不可）
  T3: 贡献利润中位档≥0 且 头部付款≥300
  T3候选: 同T3但1688样本<3 或 拿货价待核验，锁厂取得直接报价后转正
  清洁类: 拿货≤2元(须直接证据) 且 贡献利润中位档≥0 且 头部付款≥50000
  清洁类候选: 需求达标但拿货无直接证据(参考同类价=非直接证据)，
            或 淘宝需求样本=0 待补采；锁厂/补采后转清洁类
  组合组件: 亏损 + 需求大(≥30000) + 可组包(量化:组合后按目标套装
            售价重新测算，套装贡献利润≥0才进入)；禁止独立销售；
            否则→暂缓/换货源
  组合潜力候选: 需求≥30000 + 商品形态适合组包 + 单卖经济性未验证
            或已亏损 + 尚未完成套装测算；完成测算≥0后转组合组件
  数据待重抓: 数据有效性检查未通过(价格一致性存疑)，不进入任何
            评分分层（当前触发 4 词）；并移出同品类基准池
  未定级: 数据错位/待人工核验，不进入任何执行池
  暂缓/换货源: 保守口径亏损 或 到单成本≥中位价

淘宝需求有效性门槛：淘宝有效样本=0（估算口径）的词不得进入
  正式执行层（T1/T2/T3/清洁类/组合组件），只能进候选/待补采层。

品类组（勘误3版，含基准池排除异常词）：
  CSV「品类组」列，9 组：服饰(9)/湿巾(4)/雨衣(3)/牵引绳(2)/
  胸背(2)/清洁手套(2)/清洁工具(1)/项圈(1)/杂项套装(1) = 25。
  同品类基准 = 同品类组内【除当前被检查词之外】且【未被判定为
  数据待重抓】的 1688 样本≥3 词的中位成本(保守拿货价)中位数；
  排除自身/异常词后无同行词 → 无独立同品类基准，仅执行本词
  内部跨度检查，标供应链核验。

数据有效性检查（勘误3版，全量执行 + 基准池排除异常词）：
  检查范围：全部已评分词（含正式层/候选层/暂缓层），凡 1688
  有效样本≥2 且可计算者一律执行，不因层别豁免。
  第1步【语义/规格匹配】：错品/规格错位 → 该条判无效剔除。
  第2步【价格一致性】：有效样本≥2 时，固定公式 = 本词有效报价
    中位数 vs 同品类组基准（排除自身 + 排除已判数据待重抓词）；
    触发 = 样本内跨度>2倍（中位/最低>2 为确定触发下界）且
    中位数偏差>±50%。
  第3步【分流】：价格存疑→数据待重抓（并移出基准池）；剔除后
    有效=0→候选层（1688样本记0）；检查通过且样本<3→候选规则；
    样本≥3→正常评分。
  当前触发：4 词（杀菌湿巾/冬季加厚/边牧/小型犬冬装）。

需求指标：头部单品付款（淘宝实抓，非整页累计；样本=0 时为估算
  口径，不得进正式执行层）。
1688价格：未核厂用有效报价中位数；最低价仅作降本空间；
  保守价与最低价差异>1.5倍 → 标「待供应链核验」。
