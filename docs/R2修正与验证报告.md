日期：2026-09-19。依据用户提供的 R2 压缩包，审查基线为 `8af2f822b46b3d6c962070c13052645f5f780010`。

## 已验证结果

- Windows/Python 3.11.15 隔离目录默认 unit/integration 全套：**214 passed，2 warnings**。未跳过默认测试；没有安装或升级依赖。两条警告来自已有 Starlette/httpx/anyio 弃用提示。
- 回归包含 HTTP 五商品链路（创建/证据/报价/预测/素材/独立审阅/批次）、不可变方案、审批、异步任务、真实 worker 心跳、账单、恢复、CSV、版本选择与并发接受。提供方全部为本地假适配器，不能作为真实执行证据。
- 浏览器实际抽查：测试账号登录 → 网页创建模拟商品 → 保存选品事实 → PROXY 来源生成 WAIT。截图与界面观察确认；未宣称浏览器完整执行五商品全流程。
- Windows 隔离副本实际运行：重复启动不替换网页实例；单独停止 worker 后可补起且网页 PID 不变；停止后 8512 端口释放。兼容 Windows venv 启动器的子进程及 PowerShell 5/7 时间解析差异。
- 审阅员独立检查发现的旧备份 PREPARED 重发风险已修正：恢复后先进入 UNKNOWN/待核对，人工证据核对完成才解锁。备份异常退出留下的维护标记由进程文件锁判断是否仍有效，失效标记不会永久锁死任务。
- 新增“创建账号.cmd”，登录页增加首次账号创建提示。既有账号、密码和业务数据不重置。
