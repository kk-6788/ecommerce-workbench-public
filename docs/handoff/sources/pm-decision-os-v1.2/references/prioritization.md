# Prioritization

## Objective

Choose what deserves resources now.

Prioritization is not ranking everything with a formula.

Use:

1. Kill Filters
2. Ranking
3. Confidence Adjustment
4. Final Judgment

---

# 1. Kill Filters

Eliminate candidates with critical violations.

Examples:

- Negative contribution margin
- Legal or regulatory risk
- Supply instability
- Excessive return risk
- Capital requirement beyond budget
- No demand evidence
- Commodity competition without advantage
- Unacceptable CAC
- Long payback period
- Operational complexity beyond capability

A candidate that fails a critical survival constraint should not be rescued by a high composite score.

---

# 2. Ranking Frameworks

## ICE

Useful when data is limited.

Typical dimensions:

- Impact
- Confidence
- Ease

Use relative ranking, not false precision.

## Value / Effort

Useful for fast comparison.

Prefer when:
- Team is small
- Data is weak
- Choices are reversible

## RICE

Useful when reasonable estimates exist.

Reach × Impact × Confidence ÷ Effort

Do not use RICE when Reach is invented.

## MoSCoW

Use for requirement classification.

- Must
- Should
- Could
- Won't

## Kano

Use to distinguish:
- Basic expectations
- Performance features
- Delighters

## WSJF

Use when cost of delay matters.

---

# 3. Confidence

Confidence should depend on evidence.

High:
- Behavioral / transaction data
- Repeated patterns
- Direct relevant data

Medium:
- Multiple consistent market signals

Low:
- Opinions
- Weak proxies
- Sparse data

Do not make low-confidence inputs appear reliable with decimals.

---

# 4. Scoring Model Audit

Check:

### Variable Validity
Does the variable represent something useful?

### Data Quality
Where does the input come from?

### Weight Logic
Why this weight?

### Double Counting
Are two variables measuring the same thing?

### Scale Compatibility
Are normalized inputs comparable?

### Threshold Validity
Are cutoffs empirically justified?

### Decision Validity
Does the final score predict real outcomes?

---

# 5. Output

For each candidate provide:

- Kill Filter Result
- Score / Rank if useful
- Confidence
- Key Evidence
- Main Risk
- Reason for Priority
- Recommended Action
