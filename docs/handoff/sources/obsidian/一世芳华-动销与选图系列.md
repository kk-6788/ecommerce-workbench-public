## 〇、他的电商理论链条（系列定位）

一世芳华反复强调国内电商的底层逻辑就六个字：**拍照、上架、做动销**。更完整地说，他把电商拆成一条链：

**选品 → 拍照/选图 → 上架 → 做动销 → 维护（好评/评论/品退）**

- 选品篇：9/3 已提炼（高频扫新品→微改良→快速上架测，避开卷价格类目）
- 本篇：**动销** + **选图/拍照** 两块补齐
- 他自己的原话（2026-07-26视频）：电商成功的关键因素=选品、拍照片、做动销、维护好评评论区和品退；**选品和拍照片最重要，运营的重要性相对较低**

## 一、动销篇

### 1.1 什么是动销（vs 刷单 vs 补单）

| 概念 | 定义 | 对链接的影响 |
|---|---|---|
| **动销** | 链接**刚上架时**做的少量销量+评价操作 | 有好处：提高曝光、帮助推流 |
| **补单** | 在已有基础上补数据 | 有坏处：流量变泛 |
| **刷单** | 持续、大量的无意义成交 | 有坏处：推流不精准 |

**为什么刷单已死（2026-09-12视频核心）**：
- 平台推流逻辑是**千人千面**，根据下单人群属性推荐相似人群
- 刷单 → 下单人群属性混乱 → 流量变泛、推流不精准
- 现在**销量权重被削弱**，刷单无法提高点击率和收藏加购率——而这两个才是推流的关键

### 1.2 动销怎么做（2026-09-13视频）

1. **找亲戚朋友帮忙**：安全且便宜，避免使用昂贵的服务商
2. **培养社交能力**：脸皮要厚，多与人交流，扩大关系资源

### 1.3 动销的成本与必要性（2026-09-01视频）

- 不做动销，电商难以成功——动销是**电商的润滑剂**、链接成功的关键
- 动销成本低：**一个链接动销开支不超过10元**，是电商创业的基本开支
- 主流平台都需要动销：淘宝、拼多多、抖店、小红书、得物；**短视频和直播间也起到动销作用**

### 1.4 动销在「自然流 vs 付费」里的位置（2026-08-12视频）

| 玩法 | 做法 | 注意 |
|---|---|---|
| 自然流 | 多开店、多开发产品、复制成功产品链接 | 一个好的产品本身就具备自然流潜力 |
| 付费 | 大方投入，专注一个店一个链接 | 计划有冷启动阶段，需消耗一定金额探索人群 |

- **付费前先做动销和买家秀**，提高产品曝光转化率
- ⚠️ **微付费撬动自然流不可行**——小额投入是浪费

### 1.5 新手动销困境（2026-09-07视频）

新手做电商的五大坑：
1. 不懂产品，只能做无货源/一件代发 → 产品竞争力低
2. **资金有限，不舍得动销 → 影响链接流量**（最直接）
3. 选低客单产品 → 竞争激烈，成功概率低
4. 为省成本偷图 → 图片质量差，影响流量和售后
5. 交不起保证金 → 影响提现

结论：电商创业需资本，建议**先兼职**，确保有稳定工作和资金来支撑动销。

### 1.6 动销与买家秀/测品的关系（2026-08-02视频）

传统测品方式：
- 放在**有权重的店铺做动销买家秀**，观察收藏加购和流量曲线
- 或开付费看投产比

新型测品（免费）：小红书发产品照片+文案，坚持1-2个月，观察曝光和点赞，与已成功产品对比。

### 1.7 真实数据参考（2026-08-17视频）

公司7月开支明细：客服工资、仓储代发、美工摄影、主播工资、货物成本、平台到账、赔付补偿、**补单种草**、快递费 → 净利润约 **260多万**。教授用 Excel 表做开支明细。

## 二、选图/拍照篇

### 2.1 为什么选图重要：流量分配逻辑（2026-08-16视频）

电商平台流量分配取决于**点击率**和**收藏加购率**：
- **点击率 = 访客数 / 曝光量**：点击率高 → 获得自然流量
  - 影响因素：款式吸引人、价格低、**图片拍得好**
- **收藏加购率 =（收藏数+加购数）/ 访客数**：高 → 获得持续流量，且推流更精准
- ⚠️ **转化率并非最重要**——点击率和停留时间才是关键，提高用户对产品的兴趣

### 2.2 判断店铺问题的三个口诀（2026-09-05视频）

| 症状 | 诊断 |
|---|---|
| 收藏加购率低 | 流量不精准（卖价高 或 人群不精准） |
| **首图点击率低** | 无自然流量（图片、产品、价格都有影响） |
| 品退超标 | 店铺断流，影响收藏加购率和平台推流 |

**收藏加购率和点击率 = 影响平台推流的关键因素**（转化率对推流无帮助）。

### 2.3 「嗯啊」替换图法（2026-08-29视频，选图核心）

**方法**：把**高点击率的电商图**上的产品，替换成自己的产品，保持其他元素（场景/构图/背景）不变 → 提高自己链接首图的点击率 → 增加自然流量、加快平台推流速度。

**素材来源**：
- 参考同行的高点击图
- 小红书高点赞笔记图
- ⚠️ **避免同平台找图**（防查重）：可跨平台或在别处搬运，也可轻微修改图片降低相似度

**效率**：一小时可替换十几套图（AI 作图）。

### 2.4 非常规图起流量，常规图稳流量（2026-08-07视频）

抖店商品卡流量起爆快但难稳定：
- **非常规角度图**：易引起点击，但可能导致转化率低（起流量）
- **常规产品图**：转化率高（稳流量）

两个稳定流量方法：
1. 绑定抖音号发短视频 → 提高转化、稳定链接流量
2. 拍摄常规产品图 → 用非常规图起流量、常规图稳流量

### 2.5 截流 = 模仿同行（2026-09-03视频）

模仿同行的：**图片、标题、SKU配置、价格、详情页描述、外漏价格** → 吸引消费者。
- 风险：平台对盗图投诉处理宽松 → 「做电商要脸皮厚」

### 2.6 用小红书练摄影和审美（2026-07-22视频）

- 在小红书搜索类目产品，关注**高赞笔记**和品牌新品预告 → 提高选品成功率
- 学习高赞笔记的**拍摄风格和角度** → 提升摄影技术和审美
- 小红书 = 电商选品 + 摄影技术提升平台

## 三、电商成功指标总表（2026-08-28视频）

电商成功的关键指标：**点击率、收藏加购率、广告投产比、品退、选品**
- 点击率 → 影响自然流量和广告成本
- 收藏加购率 → 反映产品市场热度
- 广告投产比 → 决定盈利
- 品退 → 对链接流量影响大
- 选品 → 选好卖且价格便宜的产品

## 四、对 SparkPet 的适配建议

### 动销侧
1. **当前店铺动销缺口**：SparkPet 淘宝店新链接没做过动销，按他的理论=链接没曝光。可低成本起步：找亲戚朋友（真实单，独立地址/支付/设备，和救生衣破零口径一致）在**新链接上架时**做 3-5 单 + 好评，一个链接预算 ≤10 元
2. **动销 ≠ 刷单**：禁止用服务商/平台刷单——千人千面逻辑下会毁掉店铺标签，和 KK 已确立的「真实单」红线一致
3. **短视频和直播间也起动销作用**：抖音店发短视频（AI造物号/内容号）本身就是动销动作，与内容管线天然合一
4. **买家秀是测品前奏**：测新品前先做动销+买家秀，再观察收藏加购曲线

### 选图侧
1. **嗯啊替换图法直接可用**：SparkPet 产品图可以拿**抖音/淘宝宠物类目高点击主图**做场景参考，用 AI 替换成自己产品（保持场景/构图），提高首图点击率——注意跨平台找素材防查重
2. **首图点击率是 SparkPet 当前最该盯的指标**：猫砂伴侣 CTR 0.94% vs 同行 5.66%（2026.9.11诊断），按他的口诀=首图有问题，主图重做是正确方向，且要继续迭代到点击率过线
3. **非常规图起流量**：抖店商品卡可用非常规角度图（猫视角/使用场景特写）起流量，详情页用常规图稳转化
4. **小红书练审美**：宠物类目高赞笔记图=现成的选图素材库+审美训练场，和 SparkPet 小红书内容管线合并

### 红线提醒（辩证看）
- 他做的是**鞋服供应链自有产品**，动销+铺链接打法建立在货在自己手里、成本可控的前提上；SparkPet 目前走一件代发/白牌测款，动销成本可控但**链接数量打法要克制**（先验证 1 个品再复制，不铺一堆没验证的链接）
- 「截流=模仿同行」有**盗图/侵权风险**：借鉴场景构图可以，直接抠图搬运同行主图=违规，SparkPet 不碰
- 他说「运营不重要」是因为**他自己有供应链+美工团队**，对 KK 仍要用内容补产品力（9/3 已确认）
