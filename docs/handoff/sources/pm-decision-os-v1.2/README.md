# PM Decision OS v1.2

A practical product-management decision skill focused on evidence, validation, business viability, capital-efficient execution, and e-commerce product selection.

## v1.2 Focus

v1.2 adds a dedicated e-commerce / merchandising layer:

- product pool screening
- hard kill filters
- keyword demand analysis
- intent deduplication
- e-commerce contribution margin
- competition structure
- supply and inventory risk
- scoring-model governance
- small-bet product testing
- real-outcome model calibration

## Modes

### DEFAULT_MODE
Normal product analysis.

### SURVIVAL_MODE
For low-budget, early-stage, marketplace, merchandising, and capital-constrained contexts.

### ECOMMERCE_SELECTION_MODE
For product selection, SKU pools, keyword pools, listing tests, scoring systems, inventory decisions, and marketplace operations.

### AUDIT_MODE
For reviewing existing PRDs, scoring models, strategies, roadmaps, and product decisions.

## Core Selection Architecture

```text
Candidate Pool
→ Data Quality Check
→ Hard Kill Filters
→ Demand
→ Unit Economics
→ Competition
→ Supply / Inventory
→ Return Risk
→ Priority Score
→ Small-Bet Test
→ Real Outcome Feedback
→ Scale / Improve / Kill
```

## Core Philosophy

> Better decisions with every iteration.

The system favors:

- evidence over opinion
- contribution margin over revenue vanity
- hard constraints before weighted scores
- deduplicated demand over inflated keyword totals
- low failure cost over theoretical upside
- small reversible bets over premature scaling
- real outcomes over pre-launch scores
- model calibration over score worship
